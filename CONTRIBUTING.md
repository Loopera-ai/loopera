# Contributing

This repository contains Loopera's public product material. It does not
contain the application source or proprietary research implementation.

Use an issue to report inaccurate claims, broken links, accessibility
problems, or unclear documentation. Pull requests should stay within the
public documentation scope and should explain the source for factual or
quantitative claims.

Do not submit proprietary datasets, credentials, client information,
production configurations, internal prompts, candidate formulas, or private
research output. Report security issues through the private process in
[SECURITY.md](./SECURITY.md).
