# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues.

Use GitHub's private vulnerability reporting form:

https://github.com/Loopera-ai/loopera/security/advisories/new

If that form is unavailable, open a public issue asking the maintainers for a
private reporting channel, but do not include vulnerability details.

Include the affected material or component, reproduction details, potential
impact, and a safe way to contact you. The maintainers will acknowledge a
complete report as soon as practical and coordinate disclosure after triage.

This repository currently distributes public product documentation rather
than the Loopera application source. Reports about the hosted product should
still use the private channel above.
